# The Shires Post Office

Static HTML + CSS website. No JavaScript, no build step, no dependencies.

## Quick start
1. Open `index.html` in a browser — that is the whole site running.
2. Push these files to the root of a GitHub repo, then Settings → Pages → Deploy from branch `main`, folder `/`.

## Before you publish
See **HANDOFF.md** in the parent package, section 2. In particular:
- Replace `[ADD BRANCH PHONE]` and `[ADD BRANCH EMAIL]` placeholders
- Replace the placeholder images (exact sizes in HANDOFF §4)
- Replace the domain in canonical / og / JSON-LD tags
